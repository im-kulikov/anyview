# Сведения о тайтле из внешних баз (исследование)

Задача: на странице тайтла показать жанры/темы, первоисточник и автора оригинала, возрастной рейтинг, студию, главных героев и японских сейю. У animevost этого нет, своего сервера пока нет — делаем в адаптере (ADR-30), позже это перейдёт на сервер.

## Источники (проверено 2026-10-09 запросами из облачной сессии)

| Источник | CORS из браузера | Что даёт | Замечания |
|---|---|---|---|
| Shikimori `shikimori.io/api` | `*` | жанры и темы RU, рейтинг (`pg_13`), студии, русские описания, MAL id, роли (герои RU, сейю) | `.one` редиректит на `.io`; лимит ~5 запросов/с, 90/мин; поиск по подстроке |
| AniList `graphql.anilist.co` | `*` | `source`, штат (`Original Creator`), главные герои + сейю (JAPANESE), теги | один запрос; поиск по `idMal`; имена латиницей; лимит 90/мин |
| Kitsu `kitsu.io/api/edge` | `*` | жанры, возраст, рейтинг | беднее по героям и сейю, не используем |
| Jikan (MAL) | — | — | соединение сбрасывается; не используем |
| Кинопоиск, deep-ent, yummyani | нет открытого API | — | парсить HTML из браузера нельзя (CORS), только сервером |

Вывод: цепочка **animevost → Shikimori → (MAL id) → AniList**. Shikimori даёт русские жанры, рейтинг и студию; AniList — первоисточник, автора и героев с сейю (в Shikimori сейю не привязаны к героям).

## Сопоставление тайтла

Ключ — оригинальное название animevost (часть после `/`, романдзи, как у MAL) + год (±1). Поиск Shikimori по подстроке, принимается запись, у которой `name`, `russian`, `english` или `synonyms` совпали с названием после нормализации (регистр, ё→е, пунктуация, `\`). Русское название — запасное сравнение.

Замер на 120 случайных тайтлах (`docs/research/details/match_shikimori.py`):

- строгий режим: **101 из 120 (84 %)**, неоднозначных 0, ложных пар не обнаружено;
- запасной проход (поиск по очищенному оригиналу, совпадение по префиксу) закрывает ещё 14, но среди них есть ошибочные: OVA цепляется к ТВ-серии (Lucky Star OVA → ТВ 2007), «Idolmaster: Shiny Festa» → другой тайтл, «Huyao Xiao Hongniang» → спин-офф Fanwai. Не включён.

Промахи строгого режима: названия animevost с суффиксом ОВА, сокращённый или нестандартный оригинал («OreGairu», «Futsuu no Joshikousei ga»), несовпадение номера сезона («Shiguang Daili Ren 2» ↔ «Dailiren II»), разные годы. Решение заказчика: определить большинство достаточно, нет уверенности — блок не показываем.

## Ограничения

- Китайские и корейские тайтлы: Shikimori их знает, но японских сейю нет — показываются только имена героев.
- Три запроса последовательно (поиск → карточка → AniList), страницу не задерживают; ошибка Shikimori не кэшируется, ошибка AniList убирает только его поля.
- Имена героев и сейю — латиницей (AniList).
- Теги AniList (английские, со спойлерами) не используются; жанры берутся из Shikimori на русском.

## Для сервера

Сервер хранит внешние id (`externalIds.shikimori`, `.mal`, `.anilist` — уже в контракте), сопоставляет один раз и отдаёт `GET /titles/{id}/details`. Адаптер и `details.ts` тогда удаляются.
