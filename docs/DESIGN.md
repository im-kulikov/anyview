# Дизайн anyview

## 0. Что главнее, если источники расходятся

Один порядок для всех документов пакета:

1. **Отступления от макета** (§6 этого файла) и **поведение из SPEC.md** — главнее всего.
2. **Токены и правила** этого файла (§2–§5) — сняты с макетов и сведены в систему.
3. **PNG-экспорт экранов** в `docs/design/screens/`, если заказчик его положил.
4. **Разметка макетов** `docs/design/mockups/*.dc.html` — для всего, что не описано выше.

Как читать файлы: это HTML-разметка с инлайн-стилями. Размеры, цвета, отступы и тексты — в атрибутах `style`; данные карточек — в блоке `<script type="text/x-dc">` (`renderVals()`). Запустить их вне редактора макетов нельзя: они рассчитаны на рантайм холста (`support.js`, `<sc-for>`, `<sc-if>`, `{{…}}`), а картинки-заглушки лежат в хранилище холста (`/_blob/…`). Используйте их как точную спецификацию, а не как код.

Два приёма макета, которые **не** переносить в код:
- мобильные экраны прокручивают внутренний `div.scroll` между шапкой и панелью — в коде прокручивается окно (SPEC.md §5, общий каркас);
- кнопки и чипы местами меньше 44 px — в коде зона нажатия добирается до 44 px (§2, «Форма»).

Обложки, названия и описания в макетах вымышлены. В продукте — реальные данные из API.

### Брейкпоинты

- `< 360` — сетка 2 колонки.
- `360–599` — сетка 3 колонки, мобильный каркас.
- `600–1023` — сетка `auto-fill, minmax(140px, 1fr)`, мобильный каркас (нижняя панель).
- `≥ 1024` — десктопный каркас (шапка с разделами), сетка `auto-fill, minmax(168px, 1fr)`. Плеер и плейлист — `flex-wrap`: плеер `flex: 999 1 560px`, плейлист `flex: 1 1 340px` (при 1024 px они уже помещаются в ряд).

### Движение

- Ховер обложки на десктопе: `transform: scale(1.04)`, 250 мс.
- Скелетон: пульсация `opacity` 1 → 0.45, 1.4 с.
- Появление картинки: `opacity` 0 → 1, 150 мс.
- Всё выключается при `prefers-reduced-motion: reduce`.

## 4. Изображения разных размеров

- Обложка: контейнер `aspect-ratio: 2 / 3`, `img { width: 100%; height: 100%; object-fit: cover }`. Любой исходник заполняет карточку без пустот; лишнее обрезается по краям.
- Кадры серий и «продолжить просмотр»: `aspect-ratio: 16 / 9`, тоже `cover`.
- Фон тайтла: `backdrop`, если есть, иначе постер. **Всегда** размыт (`blur(28–36px)`), `opacity ≈ 0.55–0.6`, градиент к `--bg` снизу: скриншоты animevost маленькие (~711 × 400), без размытия выглядят плохо. Фон декоративный: `alt=""`.
- До загрузки — фон `--surface-3`, при ошибке — заглушка с первой буквой названия.

## 5. Тексты интерфейса

Тексты кнопок, заголовков, пустых состояний и заглушек — как в макетах, все в `src/lib/strings.ts`. Склонения («серия / серии / серий», «тайтл / тайтла / тайтлов», «голос / голоса / голосов») — через `Intl.PluralRules('ru')`.

**Подписи формата** (короткая — в карточках и поиске, длинная — в герое и `<dl>`):

| `format` | Короткая | Длинная |
|---|---|---|
| `tv` | ТВ | ТВ-сериал |
| `movie` | Фильм | Полнометражный фильм |
| `short` | Короткометражка | Короткометражный фильм |
| `ova` | OVA | OVA |
| `ona` | ONA | ONA |
| `special` | Спешл | ТВ-спешл |
| `unknown` | не показываем | не показываем |

**Подписи статуса:** `ongoing` → «Онгоинг», `released` → «Вышел», `announced` → «Анонс», `unknown` → не показываем.

**Строка «Эпизоды»:** `{released:7,total:12}` → «7 из 12»; `totalIsEstimate` → «1 из 12+»; `total` нет → «7»; у фильма строки нет.

## 6. Отступления от макета

1. **Теги на тайтле некликабельны** (в макете — ссылки): в API animevost нет фильтра по жанру.
2. **Секция «Избранное»** на главной появляется, если что-то добавлено; в макете её нет — тот же `Rail` + `TitleCard`.
3. **«Показать ещё»** на главной ведёт на `/anime`, а не догружает сетку на месте.
4. **Хлебные крошки** — только на десктопе (как в макете).
5. **Прокрутка окна** вместо внутреннего контейнера на мобильных; зона нажатия ≥ 44 px у мелких кнопок (§1).
6. **Акцентные альтернативы** — затемнённые варианты из §2, а не исходные из макета.
7. **Стрелки «‹ ›» у лент на десктопе** — в макете их нет.
8. Числа в макетах («3 603 тайтла», «1 240 голосов», «7 из 12») — примеры; в продукте — из данных.
9. **Шрифт полей ввода — 16 px** (в макете поиска 15 px): при меньшем размере iOS Safari приближает страницу при фокусе (SPEC.md §9).
10. **Панель «Список серий» внутри плеера и кнопка «Предыдущая серия»** — в макете есть только «Список серий» без описания панели; панель реализована оверлеем с `EpisodeList` (UX-IOS-01).
